This repository stores the most recent versions of the computational packages from the Laboratorio de Biometría y Modelación Forestal, led by Professor Christian Salas-Eljatib of the Universidad de Chile. The packages mentioned here can be run in the R software.

Specifically, the packages are:

  1. datana (Salas-Eljatib and Campos, 2026)
  2. biometrics (Salas-Eljatib et al 2026)

Although these are available on the CRAN repository of the R software, updates there are somewhat slower than our ongoing development, so it is preferable that you always verify the versions of the installed packages.

The .tar.gz installer is the source package (any operating system); the .zip installer is the binary package for Windows; the manual is the user documentation of the package. The date column is updated automatically at each build (UTC time, with the hour and the minutes).

1. Installation

To install a package, as explained in Salas-Eljatib (2021), you can use the install.packages() function. Below is an example with the datana package, 

install.packages("datana")

. To load this package into the session: . 

library(datana)

. The package citation is obtained via 

citation("biometrics")

. Now, you can repeat the above for the biometrics package as follows 

install.packages("datana")
library(biometrics)
citation("biometrics")

En este repositorio se almacenan las versiones más recientes de los paquetes computacionales del Laboratorio de Biometría y Modelación Forestal, a cargo del Profesor Christian Salas-Eljatib de la Universidad de Chile. Los paquetes a los cuales se hace mención se pueden ejecutar en el software R.

En específico los paquetes son datana y biometrics. Aunque estos se encuentran disponibles en el repositorio CRAN del software R, en su actualización es algo más lenta de lo que vamos desarrollando por lo cual es preferible Ud. siempre verifique las versiones de los paquetes instalados.

Los archivos instaladores de datana y biometrics tienen formato tar.gz, y además en la carpeta manuales se mantienen los documentos de uso del paquete en cuestón.

Luego de instalado un paquete, Ud. puede proceder como sigue para verificar si quedo correctamente instalado.

Llamarlos a la sesión: 

library(biometrics)
library(datana)

y para verificar la versión del paquete, puede emplear la función packageVersion() como sigue 

packageVersion("biometrics")

Cita del paquete 

citation("biometrics")
