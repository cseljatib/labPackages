This repository stores the most recent versions of the computational packages from the Laboratorio de Biometría y Modelación Forestal, led by Professor Christian Salas-Eljatib of the Universidad de Chile. The packages mentioned here can be run in the R software.

Specifically, the packages are:

  1. datana (Salas-Eljatib and Campos, 2026)
  2. biometrics (Salas-Eljatib et al 2026)

Although these are available on the CRAN repository of the R software, updates there are somewhat slower than our ongoing development, so it is preferable that you always verify the versions of the installed packages.

Click on a file name to download it.

The .tar.gz installer is the source package (any operating system) and although the .zip installer is the binary package for Microsoft Windows, I recommend you to install the packages using the source files first, and only if that does not work, try with the .zip version. The manual is the user documentation of the package and the date column is updated automatically at each build (UTC time, with the hour and the minutes).

1. Installation

To install a package, as explained in Salas-Eljatib (2021), you can use the install.packages() function. Below is an example with the datana package, 

install.packages("datana")

. To load this package into the session: . 

library(datana)

. The package citation is obtained via 

citation("biometrics")

. Now, you can repeat the above for the biometrics package as follows 

install.packages("datana")
library(biometrics)
citation("biometrics")

2. Installation from a physical file

The package installation explained above is performed from the source available on the official R server, called CRAN; however, the latest updates are available on this website. . 3. Things to keep in mind

Like any software, installing a specific R package may require other components on the computer itself, which depends on the operating system used as well as your computer's own configuration. In case you encounter any problems installing any of the above packages, the following is recommended:

  • check which extra packages the package to be installed requires. For example, in the case of datana, proceed as follows
setdiff(tools::package_dependencies("datana", recursive = TRUE)$datana, rownames(installed.packages()))

which will show exactly which packages datana will need in order to run. Similarly, for the biometrics package, you can proceed via . 

setdiff(tools::package_dependencies("biometrics", recursive = TRUE)$biometrics, rownames(installed.packages()))

.
