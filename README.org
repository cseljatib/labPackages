* The most recent updates to the lab's R packages

*To install the latest versions of the packages, download and run the script [[./InstallLabPackages.R][InstallLabPackages.R]].*

This repository stores the most recent versions of the
computational packages from the [[https://biometriaforestal.uchile.cl][Laboratorio de Biometría y Modelación Forestal]], led by Professor [[https://eljatib.org][Christian Salas-Eljatib]] of the [[https://uchile.cl][Universidad de Chile]].
The packages mentioned here can be run
in the [[https://cran.r-project.org][R]] software.

Specifically, the packages are [[https://cran.r-project.org/package=datana][datana]] and [[https://cran.r-project.org/package=biometrics][biometrics]]. Although these are available on the R software *CRAN* repository,
updates there are somewhat slower than our ongoing development, so
it is preferable that you always verify the versions of the installed packages.

The installer files for =datana= and =biometrics= are in tar.gz format, and
additionally, the user documentation for the package in question is kept in the
*manuales* folder.

After installing a package, 
you can proceed as follows to verify if it was installed
correctly. Let's assume you already have the =biometrics= and =datana= packages installed in your R version, and we want to review both packages. 
  
Load them into the session:
  #+begin_src R
library(datana)
library(biometrics)  
  #+end_src

To verify the package version, you can use the =packageVersion()= function as follows
#+begin_src R
packageVersion("datana")
packageVersion("biometrics")
#+end_src

To cite the packages, please use
#+begin_src R
citation("datana")
citation("biometrics")
#+end_src
